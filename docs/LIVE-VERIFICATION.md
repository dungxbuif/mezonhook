The first button attempt passed a flat component array. Mezon accepted the message but rendered no controls. The verified shape is an action-row array:

```js
components: [{ components: new ButtonBuilder().addButton(/* ... */).build() }]
```

The animation test used an ordinary image URL as both `url_image` and `url_position`. Mezon displayed the containing card but no animation. Until a valid position/sprite asset contract is proven, MezonHook must not claim animation support.

## Reproduce

Use Node.js 20–23.

```bash
npm ci
npm test
npm run verify:live -- --mode=dry-run
```

For a credentialed bot run, set:

```text
MEZON_BOT_ID
MEZON_BOT_TOKEN
MEZON_CHANNEL_ID=2096923994367201280
MEZON_HOST
MEZON_PORT
MEZON_CLIENT_TIMEOUT
```

For a credentialed webhook run, also set `MEZON_WEBHOOK_URL`. Run `--mode=webhook`, `--mode=bot`, or `--mode=all`. Never paste credential values into a command that will be logged.
