# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities confidentially through this repository's GitHub private security advisories. Do not open a public issue for a security report.

Include enough detail to reproduce and assess the issue, but do not include secrets. In particular, revoked or rotated Channel Webhook URLs must never be disclosed in issues, advisories, pull requests, screenshots, logs, or comments. Replace any URL with a clearly non-functional placeholder.

If you believe a webhook URL was exposed, revoke or rotate it in Mezon first, then submit a private advisory without the URL.
